# DSA-Problems

A collection of Data Structures and Algorithms problems implemented in Java. This repository is organized by topic, making it easy to browse, practice, and understand Java solutions for common coding interview problems.

## Repository Structure

| Folder | Contents |
| --- | --- |
| [`Arrays`](./Arrays) | Problems involving array traversal, searching, insertion, deletion, subarrays, and array manipulation |
| [`BitwiseOperators`](./BitwiseOperators) | Problems based on binary representation and bitwise operations such as AND, OR, XOR, shifts, and masks |
| [`Deque`](./Deque) | Practice problems using double-ended queues and deque operations |
| [`Hashing`](./Hashing) | Problems using hash sets, hash maps, frequency counting, duplicates, and efficient lookups |
| [`LinkedList`](./LinkedList) | Singly and doubly linked-list operations, including traversal, insertion, deletion, reversal, and cycle detection |
| [`Mathematics`](./Mathematics) | Number-theory and mathematical problems such as factors, divisibility, prime numbers, and modular operations |
| [`Matrix`](./Matrix) | Two-dimensional array problems involving traversal, rotation, searching, and matrix transformations |
| [`Queue`](./Queue) | Queue implementation and problems involving FIFO operations, circular queues, and queue applications |
| [`Recursion`](./Recursion) | Recursive problem-solving techniques, base cases, backtracking foundations, and divide-and-conquer examples |
| [`SortedArray`](./SortedArray) | Problems focused on sorted arrays, binary search, merging, and searching in sorted data |
| [`Sorting`](./Sorting) | Sorting algorithms and problems that require arranging or ordering elements |
| [`Stack`](./Stack) | Stack implementation and problems using LIFO operations, expressions, brackets, and monotonic stacks |
| [`String`](./String) | String manipulation problems, including pattern matching, palindromes, frequency analysis, and character operations |
| [`Tree`](./Tree) | Binary tree and binary search tree problems, including traversal, height, views, search, and insertion |

## Language

- **Java** — primary and only language used in this repository.

## How to Use

1. Select a folder based on the data structure or algorithm you want to practice.
2. Open a Java file to review the problem implementation.
3. Compile and run the program using a Java compiler or IDE.
